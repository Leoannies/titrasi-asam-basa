# Panduan Lab Maya Titrasi Asam-Basa

## Pendahuluan
Lab Maya Titrasi Asam-Basa ini dirancang untuk memudahkan siswa memahami prosedur titrasi, perhitungan molaritas asam, serta penentuan titik akhir titrasi dengan bantuan indikator Fenolftalein (PP).

## Fitur Utamanya:
1. **Halaman Muka**: Berisi opsi untuk memulai praktikum dan melihat panduan.
2. **Pengaturan Variabel**: Pilihan alternatif Molaritas Basa (Mb) dan Volume Asam (Va).
3. **Variasi Otomatis**: Setiap kali simulasi diulang, Molaritas Asam (Ma) akan diacak secara otomatis sehingga memberikan tantangan bagi siswa untuk menghitung secara manual.
4. **Peringatan Visual & Audio**: Memperingatkan pengguna saat mendekati titik akhir titrasi.
5. **Penutup Perhitungan**: Menyembunyikan hasil perhitungan agar siswa berlatih menghitung mandiri sebelum melihat kunci jawaban.
6. **Fasilitas Tambahan**: Tombol Fullscreen dan Informasi Penulis Prompt.
