===================================================
LAB MAYA TITRASI ASAM-BASA (VIRTUAL LAB)
===================================================

Penulis Prompt: Leonardus Annies Widya Poetranto, S.Pd.

Struktur Folder:
- index.html           : Aplikasi utama laboratorium maya (Rasio 16:9).
- /gambar              : Berisi aset gambar (Logo Kemendikdasmen & Karakter Anime).
- /suara               : Berisi efek suara titrasi (tetesan, peringatan, titik akhir).
- /docs                : Dokumentasi dan panduan praktikum.
- README.txt           : Petunjuk umum berkas ZIP.

Cara Membuka Aplikasi:
1. Ekstrak seluruh isi file ZIP ini ke komputer Anda.
2. Buka berkas `index.html` menggunakan browser pilihan (Google Chrome, Edge, Firefox, dll).
3. Selamat mencoba praktikum virtual!
